第一次部署（最短路径）

1. GitHub 新建仓库：2c-product-radar
2. 上传本项目全部文件
3. GitHub → Settings → Secrets and variables → Actions → New repository secret
   Name: PRODUCTHUNT_TOKEN
   Secret: 你在 Product Hunt API Dashboard 生成的 developer token
4. 可选：再添加 OPENAI_API_KEY
5. GitHub → Actions → Product Hunt Daily Sync → Run workflow
6. 成功后 Settings → Pages → main / root 开启 GitHub Pages
7. 打开 https://<你的用户名>.github.io/2c-product-radar/dashboard/

注意：不要把 token 写进 .env 后提交到 GitHub；.env 已在 .gitignore。
